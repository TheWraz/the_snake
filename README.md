# The Snake — классическая игра «Змейка» 🐍

## 📌 О проекте

Классическая аркадная игра «Змейка», написанная на Python с использованием библиотеки Pygame. Игрок управляет змейкой, которая движется по полю, собирает яблоки и растёт в длину. Цель — набрать как можно больше очков, не столкнувшись с собственным хвостом.

Проект реализован с соблюдением принципов **объектно-ориентированного программирования** (ООП).

## 🎮 Правила игры

- Змейка движется непрерывно в одном из четырёх направлений (вверх, вниз, влево, вправо)
- Игрок управляет направлением с помощью стрелок на клавиатуре
- При съедании яблока змейка увеличивается на один сегмент
- При столкновении с собственным хвостом игра начинается заново
- Змейка **не умирает при столкновении с границей** — она появляется с противоположной стороны поля

## 🛠 Технологии

- **Python** 3.12+
- **Pygame** — библиотека для создания игр
- **Pytest** — тестирование
- **Flake8** — проверка кода на соответствие PEP8

## 🧱 Архитектура (ООП)

Проект построен на трёх основных классах:

| Класс | Назначение |
|-------|------------|
| `GameObject` | Базовый класс для всех игровых объектов (позиция, цвет, метод отрисовки) |
| `Apple` | Яблоко — появляется в случайном месте, при съедании перемещается |
| `Snake` | Змейка — управление движением, ростом, проверка столкновений, сброс состояния |

### Ключевая логика

- Змейка представлена списком координат сегментов
- При движении: новая голова добавляется в начало списка, последний сегмент удаляется (если змейка не выросла)
- При съедании яблока: длина змейки увеличивается, яблоко перемещается на новую случайную позицию
- Столкновение с собой: полный сброс игры

## 📦 Установка и запуск

1. Клонировать репозиторий
```
git clone https://github.com/TheWraz/the-snake
cd the-snake
```

2. Создать и активировать виртуальное окружение
```
python -m venv venv
source venv/Scripts/activate
```

3. Установить зависимости
```
pip install -r requirements.txt
```

4. Запустить игру
```
python the_snake.py
```
